RentWheels - Vehicle Rental Management System (VRMS)

RentWheels is a full-stack Vehicle Rental Management System developed using PHP, MySQL, JavaScript, HTML, and CSS.
The platform allows users to browse, book, and manage rental vehicles such as bikes and cars with a modern dashboard interface.

It includes secure authentication, booking management, notifications, file uploads, password reset functionality, and responsive UI design.
